# Resmi Dilekçe Üretici 2026

## Dünyanın En Ciddi, En Resmi, En Bürokratik Dilekçe Makinesi

Bu repository, Türkiye Cumhuriyeti Devleti'nin en derin bürokrasi katmanlarından ilham alınarak tasarlanmıştır. Amacımız basittir: Siz dilekçenizi yazın, biz onu **resmen** reddedelim veya **sonsuz onay sürecine** sokalım.

### Nasıl Çalışır?

1. `python dilekce.py` çalıştırın.
2. Konu yazın.
3. Makine size 47 sayfalık bir dilekçe üretsin.
4. İmza atın. İmza şarttır. İmzasız dilekçeler otomatik olarak çöpe gider (ve çöp de resmi bir süreçtir).

### Özellikler

- %99.7 oranında "Eksik evrak" cevabı
- Rastgele "Üst yazıyla sevk edildi"
- Gerçekçi bekleme süreleri (3-18 yıl)
- Özel gizli bölüm (kimse bulamaz)

### Kurulum

Python 3.x yeterlidir. Bağımlılık yok. Çünkü bürokrasi bağımlılık sevmez.
